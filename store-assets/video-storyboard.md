# CheckLinks Chrome Web Store video storyboard

Target length: 20 seconds. Record at 1920x1080 and export as MP4 for upload to YouTube.

## 0:00-0:04 — Start a scan

- Show a content-heavy webpage in Chrome.
- Select the CheckLinks toolbar icon.
- On-screen text: `Check every link in one click.`

## 0:04-0:08 — See results in context

- Let the results panel populate while links receive colored outlines and status badges.
- On-screen text: `See broken links and redirects right on the page.`

## 0:08-0:12 — Focus on problems

- Select the **Broken** filter, then select one result to jump to its matching link.
- On-screen text: `Filter the noise. Go straight to the problem.`

## 0:12-0:16 — Understand failures

- Show the **Other** filter and a detailed timeout or network-error message.
- On-screen text: `Know what failed—and why.`

## 0:16-0:20 — Export and finish

- Select **Export CSV**, then end on the CheckLinks name and icon.
- On-screen text: `Export a clean report. No account. No tracking.`
- Final card: `CheckLinks – Broken Link Checker` and `Add to Chrome`.

Keep the cursor movement deliberate, avoid narration that duplicates the on-screen text, and use the same blue, green, yellow, and red palette as the extension UI and store screenshots.
